--- description
A Connect Four game stores its board in a two-dimensional array called `board`, with 6 rows and 7 columns. `board[0]` is the top row and `board[5]` the bottom row. Each element is `"."` for an empty space, or `"R"` or `"Y"` for a red or yellow counter. Counters dropped into a column fall to the lowest empty space in it.

Write the function `drop(board, column, counter)`, which drops `counter` into `column` (0 to 6). It places the counter in the lowest empty space of that column and returns the row it landed in. If the column is full, or the column number is not 0 to 6, the board is left alone and it returns `-1`.

**[5 marks]**
--- hints
- Check the column number first. Then look up the column from the bottom row (5) towards the top (0).
- The first `"."` you meet is where the counter lands: put it there and return that row. If you reach the top without finding one, the column is full.
--- starter
def drop(board, column, counter):
    pass
--- solution
def drop(board, column, counter):
    if column < 0 or column > 6:
        return -1
    for row in range(5, -1, -1):
        if board[row][column] == ".":
            board[row][column] = counter
            return row
    return -1
--- explanation
One mark each, up to 5:

- Rejects a column number outside 0 to 6.
- Searches the column from the bottom row upwards.
- Finds the first empty space.
- Places the counter there and returns that row.
- Returns `-1` for a full column without changing the board.
