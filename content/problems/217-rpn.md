--- description
Some calculators work in **postfix** notation, where the operator comes after its two numbers: `3 4 +` means 3 + 4. No brackets are ever needed, and a stack evaluates it easily:

- read the tokens from left to right
- a number is **pushed** onto the stack
- an operator **pops** two numbers, applies itself, and pushes the result

When the tokens run out, the answer is the one number left on the stack.

Write a function `evaluate(tokens)` where `tokens` is a list of strings: whole numbers and the operators `"+"`, `"-"` and `"*"`. Return the result as an integer.

Take care with subtraction: `["10", "2", "-"]` means 10 − 2.

### Examples

| Call | Returns | Why |
| --- | --- | --- |
| `evaluate(["3", "4", "+"])` | `7` | |
| `evaluate(["3", "4", "+", "2", "*"])` | `14` | (3 + 4) × 2 |
--- hints
- Use a list as the stack: `append` pushes and `pop` pops.
- When you meet an operator, the **first** number popped is the right-hand side. So for `-` the answer is `left - right`, where `right` was popped first.

def evaluate(tokens):
    stack = []
    for token in tokens:
        if token in ("+", "-", "*"):
            right = stack.pop()
            left = stack.pop()
            if token == "+":
                stack.append(left + right)
            elif token == "-":
                stack.append(left - right)
            else:
                stack.append(left * right)
        else:
            stack.append(int(token))
    return stack.pop()
