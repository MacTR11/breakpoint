--- description
A teacher wants to know the most common score in a test. The scores are whole numbers stored in an array called `scores`, which always holds at least one score.

Write the function `most_common(scores)`, which returns the score that appears most often. If two or more scores are equally common, it returns the **smallest** of them.

Do the counting yourself: do not use the `count` method, `Counter`, `max` or a sort.

For example, `most_common([4, 7, 4, 9, 7, 4])` returns `4`, and `most_common([5, 2, 5, 2])` returns `2`.

**[6 marks]**
--- hints
- First count how often each score appears, using a dictionary from score to count.
- Then look through the dictionary for the best score. A score beats the best so far if its count is higher, **or** if its count is equal and the score is smaller.
- Start `best` as `None` (or as the first score) so that the first score you look at always becomes the best so far.

--- solution
def most_common(scores):
    counts = {}
    for score in scores:
        if score not in counts:
            counts[score] = 0
        counts[score] = counts[score] + 1
    best = None
    for score in counts:
        if best is None or counts[score] > counts[best] or (counts[score] == counts[best] and score < best):
            best = score
    return best
--- explanation
One mark each, up to 6:

- Counts how many times each score appears.
- Handles a score the first time it is seen.
- Compares the counts to find the largest.
- Remembers which score has that count.
- Breaks a tie in favour of the smaller score.
- Returns the score (not its count).
